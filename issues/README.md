# Issues

Analysis plans and experiment cards live here as Markdown files, one file per issue.

- File name: `NNN-short-title.md` (e.g. `001-baseline-linear-regression.md`).
- First line after the title: `**Labels:** analysis-plan | experiment | ready-for-agent` (one or more).
- When an issue is finished, add `**Status:** done` and link the result (e.g. the entry in `experiments/LOG.md`).
